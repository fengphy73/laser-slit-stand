# 雷射光架設計器（laser-slit-stand）v1.3.0

高中物理單狹縫／雙狹縫干涉繞射實驗用的 3D 列印架子設計器。純靜態網頁：調參數 → 3D 預覽（與 STL 同一網格）→ 下載 binary STL。

## 三個零件（各自獨立放在桌上，三座光軸同高）

| 零件 | 做法 | 預設 |
|---|---|---|
| ① 雷射夾座 | 前、後兩個 V 形托架，筆直接擱在 V 槽裡（不滾、不晃、可直接提起）；筆擱在 V 槽時中心＝光軸高度。前方一根窄的小擋塊（寬 12 mm）只頂住筆頭下緣，出光處上方與中間完全空出，光直接射出；筆尾端面（按鍵）露在底座後方。 | 筆徑 21 mm（可調 10–30）、筆長 114 mm、V 槽 90°、托架中心距 70 mm、托架厚 8 mm、擋塊厚 6 mm、擋住筆頭下緣 4 mm（擋塊頂至少低於光軸 3 mm） |
| ② 狹縫片夾座 | 直立插槽，片子由上往下插、擱在槽底，中央開窗讓光通過，上緣露出方便拿取。 | 50×50 mm、厚 ≤2 mm |
| ③ 屏幕架 | 中央長條＋三隻腳，左中右三段插槽夾住 3 mm 塑膠瓦楞板（A4 大小，可直接當屏幕，要記錄時再貼 A4 紙）；直放／橫放可選；中段 V 形刻痕對準光點。 | 預設橫放（底座 240 mm）；直放 220 mm；插槽寬 3.4 mm |

- 光軸高度預設 35 mm（v1.3.0 由 60 降到下限，三件一起變矮），配合間隙預設 0.35 mm。
- 「狹縫座高度微調」（±5 mm，預設 0）：只上下移動狹縫片中心，用來補償實測的高度差；片子會碰到底座或光會打到窗口下緣時自動限制並提示（光軸 35 時下限為 −3）。
- 「雷射筆直徑」請填實測值：V 槽依筆徑產生，筆每粗 1 mm 光軸約高 0.71 mm（90° V 槽）。網頁會顯示 V 槽頂開口與筆的接觸點，確認筆靠在斜面上。
- 每件都放得進 25×25 cm 列印平台。
- STL 已是建議列印擺放：三件都底座朝下平放、免支撐。三件底座上緣四周 45° 倒角（1.5 mm，底座薄於 4.5 mm 時為厚度的 1/3），底面不倒角以利貼床。
- v1.3.0 依實際列印回饋：整片前擋板（含 7 mm 通光孔）會擋光，改成只擋筆頭下緣的小擋塊；取消「擋塊通光孔直徑」（舊設定中的此欄位會被忽略）；三件底座加倒角；省料（雷射座框架底座、V 托架與狹縫座下方 45° 尖頂窗、屏幕架長條＋三腳與三段插槽，三件實心合計約 310 → 178 g）；插槽寬預設 3.4 mm 配 3 mm 塑膠瓦楞板。開窗空間不夠時自動縮小或略過；測試檢查單一實體、封閉網格與免支撐（無比 45° 更平的下垂面）。V 托架、光軸與狹縫座／屏幕架其餘幾何不變，以 `tests/v120-diff.test.mjs` 對照 v1.2.0 網格驗證（只減料、功能面不變）。
- v1.2.0 依實物（筆徑 21、筆長 114）改預設並放寬筆徑到 30 mm；V 槽底至少高出底座 5 mm，筆徑大時光軸下限自動提高。當時驗證相同參數下與 v1.1.1 逐位元相同。
- v1.1.1 只把屏幕架「紙張方向」預設改為橫放，三件 STL 在相同參數下與 v1.1.0 逐位元相同。
- v1.1 只改雷射夾座；狹縫片夾座與屏幕架的 STL 與 v1.0 逐位元相同。
- 舊版逐位元比對測試（v1.0／v1.1.0／v1.1.1 的 SHA-256）在 v1.3.0 移除：底座加倒角後三件 STL 本來就全部改變，改由 `tests/v120-diff.test.mjs` 直接比對 v1.2.0 網格（`tests/fixtures/geometry-v1.2.0.mjs`）。

## 開發

```bash
npm install
npm test             # 封閉流形、V 槽光軸實測、小擋塊頂高與光路、與 v1.2.0 網格差異比對、平台尺寸、光軸實測（網格射線量測）、極端參數
npm run build:pages  # 建置到 docs/（含 .nojekyll），GitHub Pages 用 main /docs
```

所有資源皆為相對路徑，可部署在子路徑（例如 `/laser-slit-stand/`）。
