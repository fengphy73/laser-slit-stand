# 雷射光架設計器（laser-slit-stand）v1.1

高中物理單狹縫／雙狹縫干涉繞射實驗用的 3D 列印架子設計器。純靜態網頁：調參數 → 3D 預覽（與 STL 同一網格）→ 下載 binary STL。

## 三個零件（各自獨立放在桌上，三座光軸同高）

| 零件 | 做法 | 預設 |
|---|---|---|
| ① 雷射夾座 | 前、後兩個 V 形托架，筆直接擱在 V 槽裡（不滾、不晃、可直接提起）；筆擱在 V 槽時中心＝光軸高度。前方有擋塊頂住筆頭，中央通光孔讓光通過；筆尾端面（按鍵）露在底座後方。 | 筆徑 14 mm（可調 10–18）、V 槽 90°、托架中心距 70 mm、托架厚 8 mm、擋塊厚 4 mm、通光孔 7 mm |
| ② 狹縫片夾座 | 直立插槽，片子由上往下插、擱在槽底，中央開窗讓光通過，上緣露出方便拿取。 | 50×50 mm、厚 ≤2 mm |
| ③ 屏幕架 | 底座長條插槽夾 A4 紙（建議紙後加墊板），直放／橫放可選；中央 V 形刻痕對準光點。紙不列印。 | 直放底座 220 mm、橫放 240 mm |

- 光軸高度預設 60 mm（離桌面），配合間隙預設 0.35 mm。
- 每件都放得進 25×25 cm 列印平台。
- STL 已是建議列印擺放：三件都底座朝下平放、免支撐（擋塊通光孔為小圓孔，可直接橋接）。
- v1.1 只改雷射夾座；狹縫片夾座與屏幕架的 STL 與 v1.0 逐位元相同（`tests/unchanged.test.mjs` 比對 SHA-256）。

## 開發

```bash
npm install
npm test             # 封閉流形、V 槽光軸實測、擋孔通光、與 v1.0 逐位元比對、平台尺寸、光軸實測（網格射線量測）、極端參數
npm run build:pages  # 建置到 docs/（含 .nojekyll），GitHub Pages 用 main /docs
```

所有資源皆為相對路徑，可部署在子路徑（例如 `/laser-slit-stand/`）。
